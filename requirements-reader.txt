# SniperPlug-Reader standalone app dependencies.
# The reader installs ONLY this set (see discloud.reader.config), not
# the bot's requirements.txt: it has no Discord connection, and its
# memory budget was measured against exactly these OCR wheels
# (2026-11-19 gate evaluation: rapidocr-onnxruntime 1.4.4 +
# onnxruntime 1.32.0 + Pillow 13.0.0 peaked at ~325 MB for the OCR
# process on a phone screenshot, inside this app's 512 MB).
# The libsql/aiosqlite/dotenv pins match requirements.txt — the
# reader uses the repo's shared runtime database layer, same as the
# HP watcher.
# Note (2026-11-19): rapidocr pulls in opencv-python, whose wheel
# needs libGL — absent on Discloud. The engine swaps in
# opencv-python-headless itself at first import (see
# sniperplug/ocr_reader/engine.py), so it is deliberately NOT pinned
# here: two opencv distributions in one resolve fight over the cv2
# package and the winner is not deterministic.
